# Puzzle pictures

Add a picture: put a JPG or PNG here (about 1600 px wide is plenty) and add it to `pictures.json` as `{ "file": "name.jpg", "sound": "pig" }`. `sound` is optional: it names an Animal Friends recording (`../NARBEANIMALFRIENDS/sounds/animals/<sound>.wav`) played when the puzzle is finished. The cormorant uses the flamingo, the closest bird with a recording. The game centre-crops each picture to the shape of the puzzle type, so keep the subject near the middle. Bright, clear pictures with one subject work best.
